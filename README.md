A program that writes one original one-line dad joke — a single line, 82 characters — to `/output/entry.txt` for make.fun's "The One-Liner Groan-Off" bounty. The joke is a fresh twist, written for this bounty rather than recycled from the classics: a dad is asked for his best joke and answers by pointing at his own son — the son *is* the joke. Setup and punchline land inside the one line, with no wasted words.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (UTF-8, one line, 82 characters) and verifies the file on disk byte for byte.
